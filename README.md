# Management App

A Flutter Product & Order Management App developed as part of the Flutter Developer technical assignment.

## Features

- User Login
- Product Listing
- Product Search
- Product Details
- Add to Cart
- Increase / Decrease Quantity
- Remove from Cart
- Cart Persistence
- Checkout
- Form Validation
- API Error Handling
- Pull to Refresh

## How to Run

1. Clone the repository.
2. Open the project in Android Studio or VS Code.
3. Run:
